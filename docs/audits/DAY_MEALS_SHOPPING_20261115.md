# 日別の食事・買い物リスト（2026-11-15）

キャンプの開始日から終了日まで、各日の朝・昼・夜を表示。3日間は9枠で、終了日の夜も選択できる。自炊・コンビニ・菓子パン・カップ麺・外食・未定を保存し、内容、全体数量、買う／持参、メモを設定する。自炊は既存のギア／食材など6視点の料理提案へ日付・食事枠を引き継ぐ。

買い物は同じ正規化品名・同じ単位の必要数量を合算する。未購入／購入済み、手動追加、手動分の削除・復元、コピーを実装。単位変換や価格推定はしない。外食などへ変更した枠の未購入食材は現行リストから外し、元の献立と購入済み履歴は残す。自炊へ戻すと再利用できる。カップ麺では給湯と箸・ごみ袋を準備に追加する。

保存はIndexedDBトランザクションで食事・買い物・準備を一括反映。二重送信、別編集との競合、容量エラーを扱う。ネイティブカレンダーは共通の非表示活動コンテキストを利用し、元の予約・日付・メモを変更せず予定の重複を作らない。閲覧だけでは保存しない。
