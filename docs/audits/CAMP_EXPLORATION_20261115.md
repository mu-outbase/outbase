# キャンプ場内の探索記録

利用者の「サイト探索」は、キャンプ場内を歩き、区画サイト・炊事場・トイレなどを記録する体験。キャンプ場の検索比較という以前の解釈を訂正した。

## 今回の機能

現shellのキャンプ予定詳細に「場内探索・記録を開く」を追加。既存v44カレンダーでも、キャンプ種別の保存済み予定を開くと「場内探索・記録」から利用できる。

探索開始/終了を独立した記録として保存し、親キャンプの実行状態やタイマーを変更しない。開始済み探索は再読込で復元。同じキャンプで探索を繰り返しても以前の記録は残す。

区画サイト・炊事場・トイレ・その他を分類し、サイト番号/名前・特徴・任意の写真1枚・任意の現在地を保存できる。位置は利用者が「現在地を付ける」で一度取得する。GPS拒否や圏外でも写真/メモは位置なしで保存可能。位置が古い/精度が悪い場合は取り直しまたは明示的な除去を求め、架空の地点を作らない。

保存地点は場内地図と分類フィルター付き一覧で表示。地図の番号を押すと対応する記録と写真を開く。地図は指/矢印キーで移動、拡大縮小/全地点表示が可能。背景は既存と同じOpenStreetMapを使用し、通信がないときも保存地点・一覧・写真は端末から表示する。歩行ルートの自動追跡・背景地図の全面オフライン提供を追加するものではない。

## 保存と既存予定

観察記録と写真Blobは同じIndexedDB transactionで保存。失敗時は両方を巻き戻し、選択写真と入力を保持する。同じ保存要求の再試行/二重送信は重複を作らない。別キャンプの探索sessionは使用できない。探索終了後の新規保存も拒否。再表示・位置取得・写真表示だけでは観察記録を作らない。

v44の元イベントは更新しない。明示的な探索開始時だけ、元イベントIDに紐づく内部の記録保存先と探索sessionを一括作成する。以後は同じ保存先を使用。内部保存先は通常の予定一覧から除外し、calendar_entriesも作らないため予定を二重表示しない。記録は対象の予定単位で保持し、別日程の同名キャンプ場に自動で混ぜない。

入力中の再描画はフォームDOMを保持し、写真選択・位置・メモを維持する。PWA更新は探索フォームが開いている間に再読み込みしない。未保存のメモ/写真があると探索終了を保留する。

## 検証

Node80件、構文検査、SW資材URLの網羅と重複なしの確認成功。Pixel7エミュレーションの独立保存領域で以下を確認:

- キャンプ詳細からの入口、表示だけでは書込なし、探索開始の二重操作防止。
- サイトA12の位置・写真・特徴、4分類、HTML文字列の安全表示、GPS拒否時の位置なし保存。
- Blob書込失敗時に観察記録も巻き戻し、写真/入力保持、再試行と二重保存防止、元の画像バイト保持。
- 入力/写真を持つまま再描画、PWA再読み込み要求の保留。
- 分類フィルター、地図の拡大/キー移動、地点から記録を開く、写真の再表示。
- 未保存内容があると探索終了しない、オフライン保存/終了/再起動、再探索と履歴保持。
- 別キャンプのsessionを拒否、親キャンプの状態/メモ/タイマー不変。
- 既存カレンダー予定からの入口、読取だけでは内部保存先も作成しない、元イベント/参加者/メモの保持、予定重複なし、入力保持、再読込/再探索で同じ保存先を利用。

既存の写真保存・バックアップ、スマホの戻る操作、天気更新中のカレンダー入力保持、旧PWA更新・記録/Blob保持・オフラインの回帰試験も成功。Android実機のカメラ・位置精度・キーボードは未確認。MVP全体の完成判定は保留。
