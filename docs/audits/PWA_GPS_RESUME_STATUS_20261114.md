# PWA復帰時のGPS状態表示

コタ散歩の時間・距離の直下にGPS未開始／記録中／停止中／終了を表示。時間の記録とGPSの動作が別であること、停止中の移動はルート・距離に追加されないことを明示する。活動中の停止状態では同じ場所のボタンからGPSを開始・再開できる。

GPS更新時は地図とGPS状態だけを差し替え、実行カードやメディアを再作成しない。地図側と上部のボタンのイベントは重複しないようonclickで置き換える。GPSのバックグラウンド動作・自動再開・許可要求方式・保存形式は変更しない。

Pixel 7の使い捨てブラウザで非表示・復帰を模擬し、停止表示・自動再開なし・古いGPSコールバック無視・ボタンから一度だけ再開・停止区間の距離や線の補完なし・再読み込み・一時停止／終了を確認。GPS更新前後の実行カードDOM保持も確認。開始時GPS選択の既存フロー、単体23件、構文、旧PWAからの更新・データ保持・連続更新・オフライン起動が成功。Android実機の動作は未確認。
