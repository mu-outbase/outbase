# 散歩地図の移動操作

地図の指・マウスでのドラッグ、矢印キーによる移動を追加。手動操作後は中心位置と拡大率を活動単位のメモリに保持し、GPS更新で勝手に全体表示へ戻さない。「全体」または明示的な現在地確認で手動表示を解除する。拡大・縮小も表示中心を維持する。

ドラッグ中のGPS更新は地図DOMを差し替えず、指を離したあとに最新の記録から再描画する。GPS状態・距離は更新を続け、メディアDOMには触れない。地図内はドラッグ操作とし、ページのスクロールは地図外で行う。操作ボタンは44px以上、狭い画面では操作部を折り返す。

Pixel 7エミュレーションの実タッチイベントで移動中のGPS更新とDOM保持、指を離したあとの最新点列、中心・倍率の維持、キーボード移動、全体への復帰、オフライン操作、横はみ出しなしを確認。GPS停止・再開の既存テスト、構文・SW資材チェック、旧版からのPWA更新・データ保持・連続更新・オフライン起動も成功。タイル取得は移動テストでは模擬画像を使用。Android実機は未確認。
