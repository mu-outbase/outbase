# コタ散歩の地図表示

散歩の実行画面にOpenStreetMapの背景地図、保存したGPSルート、現在地／最終記録地点、場所・駐車ピンを追加した。GPS取得前は説明を表示する。地図の拡大・縮小・全体表示に対応し、停止・再開で分かれたGPS記録を線で結ばない。終了後も履歴から記録画面を開いて確認できる。

距離計算と同じ精度・移動速度フィルターを使った点列を表示する。保存形式や既存データは変更しない。背景地図は通信が必要で、取得失敗時もルートと地点を残して取得失敗を表示する。地図タイルの地域はOpenStreetMapへのリクエストに含まれる。タイルの一括取得・事前ダウンロードは行わない。

確認: Pixel 7エミュレーションで開始、GPS2地点、ルート描画、拡大・全体表示、一時停止／再開での区間分離、終了とオフライン再読み込みを確認。既存のコタ散歩一連操作も成功。位置・点灯・実行状態の単体テスト20件、構文チェック、旧PWAからの更新・連続更新・データ保持・オフライン起動が成功。背景タイルのHTTPS取得200 image/pngを確認。検証環境のブラウザ証明書制約に対して、追加の画面検証ではPythonの証明書検証済みHTTPS取得をブラウザへ渡した。Android実機でのGPS・点灯・撮影の確認は未実施。
