# コタ散歩の画面点灯維持

コタ散歩の実行画面に「画面を点灯したままにする」を追加。利用者がONにした場合のみScreen Wake Lockを要求し、活動データや端末設定は書き換えない。

一時停止・終了・画面移動・pagehideで解除する。表示が非表示になった際も解除し、同じ画面へ戻った場合は利用者のON意図が残り、活動が記録中であれば再設定する。GPSの再開は引き続き明示操作で、点灯維持からGPS取得を開始することはない。省電力等による解除・拒否・未対応は状態を表示し、出来事やメモの記録を妨げない。

遅れて返った要求はキャンセル後に保持しない。取得後も活動の存在・削除・状態を確認し、途中終了や読み取り失敗では取得済みのリソースを解放する。

## 検証

- Node8件: 明示操作、解除、拒否、未対応、画面移動、pagehide、遅延結果、非表示／復帰、システム解除、取得待ち中の活動終了、取得後の再検証失敗。
- 隔離Pixel 7相当ブラウザ: 保存row不変、GPS拒否後も水分記録可能、非表示時解除／復帰時再設定、一時停止／終了時解除、再開で勝手に再取得しないこと、拒否時の案内、HOMEへ移動後の解放。ページエラーなし。
- 既存49件を含むNode57件、コタ散歩の開始から履歴まで、PWA旧版／連続更新・保存データ保持・オフライン実行が成功。

実際のAndroid画面の自動消灯や省電力挙動は未確認。上記ブラウザのプラットフォームAPIは疑似実装であり、実機動作の証明ではない。バックグラウンドGPS追跡を提供する変更ではない。
