# PWA散歩の一連の確認と初回登録修正

一連の操作を通す過程で、PWAを初めて登録する際のcontrollerchangeでも画面を再読み込みし、操作やGPSが中断される問題を確認した。HTMLと既存アプリ双方の更新処理で、それまでcontrollerがない初回claimは再読み込みせず、既存controllerからの更新は一度だけ再読み込みする。legacy資材もURLを更新し、SWの実際の資材一覧を揃えた。

専用テストではSW初回インストールを一時保留してから散歩・GPS・出来事記録を開始し、その後に登録を完了。ページ読み込み回数1、GPS要求回数1、画面DOM・活動ID維持、記録継続を確認した。続く本当の更新では読み込み回数が一度だけ増え、活動・出来事が残り、GPSは無断再開しない。

追加確認: コタ散歩の開始・重複防止・GPS・出来事4種・取り消し・一時停止／再開・メモ・写真・音声・オフライン終了・カレンダー時刻・履歴・保管庫・次の散歩、動画保存／再生／バックアップ検証、開始時GPS選択、GPS停止と再開、タッチ地図移動、場所ピンと駐車位置、旧PWA更新・連続更新・データ保持・オフライン実行が成功。モバイルの戻る操作・スクロール位置・横はみ出しも成功。位置情報拒否の既存テスト文言を現在の設定案内へ合わせた。

この結果は使い捨てブラウザとPixel 7エミュレーションでのソフトウェア確認。Android実機のGPS精度、撮影・録音、点灯・省電力動作は未確認。AGENTS.mdに従いOUTBASE全体のMVP完成判定は保留する。
