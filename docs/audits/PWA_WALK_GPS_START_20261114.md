# PWAの散歩開始とGPS選択

PWAを主な利用形態とし、散歩開始画面に「散歩開始と一緒にGPS記録を開始」を追加した。初期値はオフ。利用者が選んで開始した場合に限り、同じ活動の実行画面が開いたときにGPSを開始する。選択はlocalStorageへ保存し次回も表示する。散歩の保存失敗ではGPS要求を作らない。

GPS開始要求はメモリ内で一度だけ消費する。再読み込みでの無断再開、別画面・非表示時の開始、許可拒否後の自動再要求を行わない。許可拒否はOUTBASE／Chromeのサイト設定を案内する。権限の保存やブラウザの確認ダイアログは端末側の設定に従う。画面非表示・消灯時のGPS停止は引き続き明記する。

Pixel 7の使い捨てブラウザで初期オフ、開始時のGPS、再読み込み時の停止、選択の維持、既存散歩への復帰、拒否時の一度の要求、拒否後の水分記録、選択解除を確認。位置記録・要求消費と経路キャンセル・PWA資材の単体確認9件成功。旧版・長期HTTPキャッシュからのPWA更新、保存データ保持、連続更新とオフライン実行も成功。起動とshellのURLを更新し実際の読み込みURLをSWへ揃えた。
