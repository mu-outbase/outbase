# コタ散歩：開始から履歴まで

## 今回の完成条件

HOMEの「コタ散歩」→専用開始→散歩中の記録→終了→保管庫から同じ散歩を開いて見返す、を一つの導線として検証する。OUTBASE全体のMVP完成を意味しない。

## 動作

- 専用の開始ボタンで時間記録を開始する。記録中・一時停止中のコタ散歩があれば同じ活動へ戻し、二重作成しない。
- GPSは実行画面から明示的に開始する。おしっこ・うんち・水分・休憩は時刻付きで記録でき、直前の出来事を取り消せる。
- メモ・写真・動画・音声は既存の端末保存を利用する。保存済みの散歩記録は追加表示で5件を超えて見返せる。
- 終了すると記録時間・距離・出来事の件数を表示し、「散歩の履歴を見る」へ進める。保管庫から同じ履歴を開き、記録・写真・音声を再表示できる。
- 開始時は活動とカレンダーを、終了時は活動の終了状態とカレンダーの実際の終了時刻を同時保存する。通常の予定活動の日時は変更しない。
- 終了済みの散歩へ出来事を追記したり再開したりせず、次の散歩は別の活動になる。既存の汎用散歩・旧FIELD03は自動変換しない。

隔離したPixel 7相当のChromium、疑似GPSと疑似マイク、検証用画像を使用。開始の途中失敗で活動・カレンダーが両方0件に戻ること、二重開始防止、GPS距離、4種類の出来事、二重押し防止、保存失敗、取り消し、一時停止・再開・再読み込み、メモ・写真・音声の同一活動への保存、5件超のメモ表示、終了時の途中失敗の取り消し、オフライン終了・復元、実終了時刻、保管庫からの再表示、次の散歩との分離を通過。ページエラーなし。

通常の活動状態・写真・カレンダー回帰、Gate2 26/26、PWA旧版更新・連続更新・データ保持・オフライン実行、既存Node49件、npm run checkも通過。

## 使用上の境界

GPSは画面表示中のみで、画面移動・非表示・一時停止・終了で停止する。再開後はGPS開始ボタンを押す。バックグラウンドでのGPS追跡や音声文字起こしは提供しない。実Android端末のGPS精度・カメラ・マイク・インストール済みPWA確認は未実施。コタのペットプロフィールを架空に作成することはなく、専用活動の同行ラベルとして記録する。
